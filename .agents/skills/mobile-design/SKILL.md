# Diseño Mobile y Responsivo (ROLBAG)

## Propósito
Construir una experiencia real "mobile-first" o responsiva que no se sienta como un "desktop roto", sino como una App nativa.

## Responsabilidades
- **Dispositivos:** Tablet y Mobile deben diseñarse como experiencias propias.
- **Menús:** Implementar menús hamburguesa amigables o sidebars móviles bien organizadas.
- **Gestos:** Los sliders o galerías de productos deben ser `touch-friendly` (swipeables).
- **Táctil:** Los botones y enlaces deben tener al menos 44x44px de área de tap.
- **Media Queries:** Usar breakpoints estándar (ej. 768px, 992px) asegurando que el grid se adapte (de 4 columnas a 2 a 1).

## Referencia Externa
Implementación guiada por normativas de usabilidad móvil (Google Mobile Friendly Guidelines).
