# Testing Funcional y Visual (ROLBAG)

## Propósito
Verificar que la aplicación web funcione correctamente en local o staging antes de pasar a producción.

## Responsabilidades
- **UI/UX Testing:** Verificar flujos principales (Navegación al Home, abrir formulario de Contacto, probar el submit, navegar un catálogo).
- **Consola:** Revisar y validar que no haya errores de JavaScript (`console.error`).
- **Red:** Revisar errores de red (`404` en assets o endpoints).
- **Responsive:** Verificar que el layout no se rompa bajo resoluciones mobile (375px) o tablet (768px).
- **Tooling:** Entender y utilizar herramientas como Playwright si están disponibles, o instruir al usuario para verificación manual.

## Referencia Externa
Estándares modernos de QA y Web Testing (basado en Playwright/Cypress standards).
