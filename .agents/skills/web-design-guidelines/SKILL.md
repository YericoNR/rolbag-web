# Guidelines de Diseño Web y UX (ROLBAG)

## Propósito
Garantizar que todo componente de UI sea accesible, coherente y funcional.

## Responsabilidades
- **Auditoría UI/UX:** Analizar cada nueva página o componente para validar que la experiencia de usuario sea fluida.
- **Accesibilidad:** Uso correcto de contraste, tamaños de fuente legibles (ej. 16px base), atributos `aria` si hay interactividad (modales/sliders) y `alt` en imágenes.
- **Consistencia:** Mantener el mismo tratamiento de bordes (radios consistentes), la misma escala tipográfica, y la misma paleta.

## Referencia Externa
Implementación local guiada por estándares de W3C y buenas prácticas generales de UX UI contemporáneas.
