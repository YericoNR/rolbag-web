# WP-CLI y Operaciones (ROLBAG)

## Propósito
Guiar al agente en la administración y automatización de WordPress utilizando `wp-cli`.

## Responsabilidades
- **Manipulación de Contenido:** Generar o editar contenido DEMO (`wp post create`, `wp term create`).
- **Configuración:** Manipular opciones de WordPress (`wp option update`).
- **Base de datos:** Operaciones de exportación, importación o búsqueda/reemplazo (`wp search-replace`).
- **Usuarios:** Gestión de usuarios de prueba si fuera necesario.
- **Instalación:** Activar plugins o temas localmente.

## Entorno ROLBAG
- El comando base disponible en este entorno local es `.\wp.bat`. Utiliza siempre este formato.

## Referencia Externa
Implementación adaptada basándose en las necesidades del proyecto y en `https://github.com/WordPress/agent-skills`.
