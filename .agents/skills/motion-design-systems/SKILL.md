# Sistema de Consistencia de Motion (ROLBAG)

## Propósito
Unificar el movimiento a nivel sistémico para que todo el sitio web de ROLBAG se sienta fluido y consistente, como un único ente.

## Responsabilidades
- **Duración (Duration):** Definir tokens de tiempo estándar. Ej: Rápido (150ms) para hovers, Medio (300ms) para estados, Lento (500ms) para reveals estructurales.
- **Easing System:** Definir un set de easings globales y aplicarlos en todo el proyecto.
- **Enter/Exit:** Definir animaciones base para montaje y desmontaje del DOM (ej. Fade + Slide Up 20px).
- **Intensidad:** No mezclar transiciones sutiles en una sección con explosiones de movimiento en otra.
- **Jerarquía:** El elemento más importante debe llamar la atención; los accesorios deben ser sutiles.

## Referencia Externa
Reglas derivadas de patrones de Motion System de Apple y Material Design.
