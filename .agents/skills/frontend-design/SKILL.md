# Diseño Frontend y UI (ROLBAG)

## Propósito
Crear un diseño de alta calidad, corporativo, industrial, moderno y profesional.

## Responsabilidades
- **Diseño Premium:** Evita los diseños genéricos (botones redondeados gigantes, colores planos y aburridos, sombras desproporcionadas).
- **Composición y Spacing:** Usa padding generoso. Respeta las jerarquías visuales (`<h1>` vs `<p>`).
- **Grids y Layout:** Usa CSS Grid para distribuciones de 2, 3 o 4 columnas.
- **Identidad ROLBAG:** Mantén colores corporativos (dark blue, yellow/gold, neutros limpios).
- **Consistencia:** Mantén estilos de "Cards" o "Secciones" alineados a la línea estética elegida.
