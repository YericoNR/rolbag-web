# Motion Design Fundamental (ROLBAG)

## Propósito
Dotar a ROLBAG de un nivel de animación premium sin comprometer el rendimiento. 

## Responsabilidades
- **Propósito:** El movimiento nunca debe ser puramente decorativo. Debe guiar la atención (jerarquía), dar feedback (interacción) o contar una historia (narrativa visual).
- **Timing y Easing:** Utilizar curvas de easing elegantes (ej. `cubic-bezier(0.25, 1, 0.5, 1)` u `power3.out`). Evitar el easing `linear` para interfaz.
- **Choreography:** Coordinar secuencias de animaciones para que los elementos entren al unísono u ordenadamente (staggering).
- **Accesibilidad:** Respetar de manera estricta `@media (prefers-reduced-motion: reduce)` desactivando animaciones de layout y limitándolas a simples opacidades.
